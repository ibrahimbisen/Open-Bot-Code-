### Added

- Type "/" in a chat to see the slash commands of the engine. CodeBot reads the list from the engine itself when the engine version changes, saves it, and shows it in every chat. Commands and skills from the `.claude` folder of the project and from the user folder are in the list. The model, thinking level and resume commands open a CodeBot screen. All other commands go to the engine as plain text, and their output shows in the chat.
